# @weather/air-quality

Шкалы качества воздуха как данные и расчёт AQI: чистый TypeScript без Fastify, базы и интерфейса.
Единый источник категорий и AQI для карты, аналитики и серверного расчёта. Копия того же модуля
есть во фронтенде (`weather-nuu/src/shared/lib/air-quality/`): фронтенд намеренно не зависит от
этого пакета, поэтому совпадение двух реализаций доказывает общий файл эталонных значений.

```ts
import { aqi, categorize, getStandard, CATEGORY_IDS } from "@weather/air-quality";

const epa = getStandard();                 // US EPA, редакция 2024
categorize(epa, "pm25", 22.25);            // "moderate"
aqi(epa, "pm25", 22.25);                   // 75
aqi(epa, "pm25", null);                    // null: нет показания (не ноль)
```

* `CATEGORY_IDS`: шесть категорий от лучшей к худшей (для Zod: `z.enum(CATEGORY_IDS)`).
* `categorize` и `aqi` принимают **24-часовое среднее**; перед поиском концентрация усекается
  (не округляется) до разряда стандарта: PM2.5 до 0,1, PM10 до целого. Это правило EPA.
* Не число, бесконечность и отрицательные значения дают `null`. Выше таблицы результат 500.
* Региональная норма подключается файлом в `src/standards/` и записью в `src/registry.ts`.
* Цвета и CSS-переменные категорий, зоны шкал и подписи живут только во фронтенде.

## Эталонные значения (golden vectors)

`fixtures/aqi-vectors.json` (109 случаев: границы всех категорий, середины, значения «чуть выше
границы», выше таблицы, пустые и отрицательные). **Тот же файл** лежит во фронтенде
(`src/shared/lib/air-quality/aqi-vectors.json`), и тест в каждом репозитории проверяет, что
реализация воспроизводит каждый случай, а хеш `casesSha256` совпадает с содержимым.

Меняете таблицу или правила расчёта: исправьте код, выполните `pnpm vectors`, **сверьте diff файла с
официальной таблицей**, скопируйте файл во фронтенд и обновите там код. Хеши в двух
репозиториях должны совпадать (пишите это в описании PR).

```bash
pnpm --filter @weather/air-quality test       # тесты
pnpm --filter @weather/air-quality vectors    # пересоздать эталонные значения (осознанно)
```
