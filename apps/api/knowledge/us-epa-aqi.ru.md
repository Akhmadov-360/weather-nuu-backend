# Индекс качества воздуха US EPA

AQI переводит концентрацию вещества в число от 0 до 500 и в категорию. Платформа использует шкалу US EPA с границами, пересмотренными в 2024 году: верхняя граница категории «Хорошо» для PM2.5 снижена с 12,0 до 9,0 мкг/м³.

## Категории и что они значат

| Категория | AQI | Цвет | Смысл |
|-----------|-----|------|-------|
| Хорошо | 0-50 | зелёный | качество воздуха удовлетворительное, риск мал или отсутствует |
| Умеренно | 51-100 | жёлтый | приемлемо; необычно чувствительные люди могут ощутить слабые эффекты |
| Вредно для чувствительных групп | 101-150 | оранжевый | могут пострадать люди с болезнями лёгких и сердца, пожилые и дети; большинство людей нет |
| Вредно | 151-200 | красный | все могут начать ощущать эффекты, чувствительные группы сильнее |
| Очень вредно | 201-300 | фиолетовый | тревога для здоровья: риск выше для всех |
| Опасно | 301-500 | бордовый | чрезвычайная ситуация: вероятно, затронуто всё население |

## Границы для PM2.5 и PM10 (среднесуточные, мкг/м³)

| Категория | PM2.5 | PM10 |
|-----------|-------|------|
| Хорошо | 0,0-9,0 | 0-54 |
| Умеренно | 9,1-35,4 | 55-154 |
| Вредно для чувствительных групп | 35,5-55,4 | 155-254 |
| Вредно | 55,5-125,4 | 255-354 |
| Очень вредно | 125,5-225,4 | 355-424 |
| Опасно | 225,5-325,4 | 425-604 |

## Как считается число

AQI находится линейной интерполяцией внутри категории, куда попала концентрация C: AQI = (AQI_верх - AQI_низ) / (C_верх - C_низ) x (C - C_низ) + AQI_низ. Перед этим PM2.5 усекается до одного знака после запятой, PM10 до целого. Пример: PM2.5 48,2 мкг/м³ лежит в диапазоне 35,5-55,4, поэтому категория «Вредно для чувствительных групп», AQI около 132.

## Что показывает станция

Официальный AQI определён для 24-часовых средних. На платформе категория и AQI считаются по текущему показанию или по среднему за период, о котором спросили, поэтому одно показание служит ориентиром, а не официальным индексом. Датчик пыли есть только в аудитории. На улице его нет, поэтому AQI для улицы не считается.
